# LLM Engineering

**Status:** Planned

## Hands-on project
Build a provider-agnostic LLM gateway with prompt templates, schema-constrained outputs, streaming, timeouts, retry budgets and token accounting.

## Acceptance criteria
Contract tests use a fake model; real-provider smoke tests and their cost/latency are reported separately.

## Delivery requirements
Follow [the common engineering standard](../../ENGINEERING_STANDARDS.md) and [project template](../../templates/PROJECT_README.md). Publish runnable code and measured evidence before changing the status.
