# Evaluations & Reliability

**Status:** Planned

## Hands-on project
Create an evaluation harness for LLM outputs, RAG grounding and agent actions, with regression thresholds and transparent datasets.

## Acceptance criteria
Repeatable results include a baseline, task definitions, sample size, failure categories and no mock-versus-real conflation.

## Delivery requirements
Follow [the common engineering standard](../../ENGINEERING_STANDARDS.md) and [project template](../../templates/PROJECT_README.md). Publish runnable code and measured evidence before changing the status.
