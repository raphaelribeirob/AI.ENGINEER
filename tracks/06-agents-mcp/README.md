# AI Agents & MCP

**Status:** Early external scaffold

## Hands-on project
Build a tool-using agent with a tool registry, explicit permission boundaries, budgets, state management and auditable execution.

## Acceptance criteria
Success, latency, cost and tool correctness are measured on an end-to-end test suite. Existing [agent-benchmark](https://github.com/raphaelribeirob/agent-benchmark) is a scaffold with no published benchmark results.

## Delivery requirements
Follow [the common engineering standard](../../ENGINEERING_STANDARDS.md) and [project template](../../templates/PROJECT_README.md). Publish runnable code and measured evidence before changing the status.
